# Biztonsági szabályzat

## Támogatott verzió

Biztonsági javításokat a repository `main` ágán elérhető aktuális verzióhoz készítünk.

## Sérülékenység bejelentése

Kérjük, ne hozz létre nyilvános GitHub issue-t, ha sérülékenységet, adatvesztési kockázatot vagy rosszindulatú XMP-fájlhoz kapcsolódó hibát találsz.

Privát bejelentéshez használd a GitHub repository **Security advisories** felületét, vagy vedd fel a kapcsolatot a projekt tulajdonosával. A bejelentés tartalmazza:

- az érintett verziót vagy commitot;
- a probléma rövid leírását és várható hatását;
- biztonságos, reprodukálható lépéseket vagy minimális mintafájlt;
- ha ismert, javasolt javítást.

Visszaigazolásra törekszünk, majd a javítás elkészülte után összehangolt nyilvánosságra hozatalt alkalmazunk.
